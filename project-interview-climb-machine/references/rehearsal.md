# Rehearsal and Review

## Set the rehearsal

Ask the user to choose:

- cold response, Layer 1, Layer 2, or Layer 3;
- interviewer direction or role, if any;
- desired depth or pressure;
- feedback after each answer or after a short sequence.

Do not require a prepared narrative for a cold run. Use the cold response as
the candidate's baseline and possible input to M6–M8.

## Run candidate-first

Ask one interview question at a time unless the user asks for a batch. Let the
candidate finish before coaching. Do not reveal an ideal answer before the
candidate attempts the response.

Follow the candidate's chosen direction while probing genuine ambiguity,
unsupported claims, technical understanding, or likely follow-ups. Do not
manufacture aggressive pressure or unrelated trivia.

## Review

Give two or three priority observations by default. Distinguish:

- factual or technical corrections;
- unclear communication;
- missing reasoning the user may want to add;
- optional improvements rather than errors.

Ask which change the user accepts. Persist only accepted changes. When updating
an existing narrative, edit its targeted section after re-reading the current
file. Keep the rehearsal record concise unless the user asks for a full
transcript.
