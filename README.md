# Awesome Agent Skills

Personal Codex skill repository.

This repository is intentionally kept outside the default Codex skill loading
directory. The default local skill directory is:

```text
/home/agent/.codex/skills
```

This repository lives at:

```text
/home/agent/Awesome_Agent_Skills
```

Only selected personal skills should be tracked here:

- `harness-setup`
- `computer-use-agent-job`

Codex-managed system skills such as `.system/` must not be copied or committed.

To make a skill active for Codex, copy or symlink that skill directory into the
default local skill directory.
